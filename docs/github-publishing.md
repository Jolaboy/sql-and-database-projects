# GitHub Publishing Guide

## Recommended Repository Settings

Repository name:
`sql-and-database-projects`

Description:
`Portfolio-ready SQL Server projects covering database design, joins, stored procedures, reporting queries, and relational modeling.`

About:
`A curated SQL Server portfolio with practical database projects for zoo operations, bookstore records, and library management.`

Topics:

- `sql`
- `tsql`
- `sql-server`
- `database-design`
- `stored-procedures`
- `relational-database`
- `data-modeling`
- `portfolio-project`
- `database-projects`
- `ssms`

## Suggested Repository Intro

Use this if you want a short introduction for a pinned repository or portfolio site:

`This repository contains curated SQL Server projects that demonstrate relational database design, stored procedures, reporting queries, and practical business-focused data modeling.`

## Suggested Launch Checklist

1. Create the GitHub repository using the name above.
2. Add the repository description, About text, and topics.
3. Push the local repository to the `main` branch.
4. Pin the repository on your GitHub profile if this is one of your stronger SQL projects.
5. Keep `projects/` as the main review surface and treat `archive/` as supporting history only.

## Suggested Push Commands

```powershell
git add .
git commit -m "Create portfolio-ready SQL project repository"
git remote add origin <your-repo-url>
git push -u origin main
```
